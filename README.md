# ◌ Moment Calendar

> 每个值得庆祝的日子，都有好点子

按日期和行业找节日活动灵感，带倒计时、落地玩法、可复制文案。

**在线体验：** 部署后填写 https://你的用户名.github.io/moment-calendar/

## 使用方式

1. 直接双击 `index.html`，无需服务器或依赖。
2. 使用页面中的「示例」功能快速体验，填写真实数据后可导出结果。
3. 上传本目录**内部**全部文件到 GitHub 新建的公开仓库 `moment-calendar`。
4. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
5. 等待部署后访问 `https://你的用户名.github.io/moment-calendar/`。

## 技术要点

- 日期运算 · 策略内容库
- HTML / CSS / JavaScript，无安装、无构建、无外部 CDN。
- 独立的 **Moment Calendar** 视觉主题，专属 CSS 与独立导航；不依赖其他四个仓库。
- 默认本地算法可用，⚙ 可选 OpenAI 兼容 API（DeepSeek 等）；API Key 仅存在本地浏览器。
- 使用在线 AI 时，请避免提交真实敏感客户数据至第三方服务。
